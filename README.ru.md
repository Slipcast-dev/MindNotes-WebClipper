# Web Clipper для MindNotes

[English](README.md) · **Русский**

[![CI](https://github.com/Slipcast-dev/MindNotes-WebClipper/actions/workflows/ci.yml/badge.svg)](https://github.com/Slipcast-dev/MindNotes-WebClipper/actions/workflows/ci.yml)

Плагин для [MindNotes](https://github.com/Slipcast-dev/MindNotes-Apple-Silicon) — личной базы знаний для Mac.
Сохраняет из Chrome и Safari в новую страницу:

- **Статья** — основной текст без меню и рекламы, с заголовками, списками, таблицами, кодом и картинками;
- **Выделение** — только выделенный фрагмент;
- **Закладка** — карточка ссылки;
- **Скриншот** — видимая часть вкладки;
- через правый щелчок — страница, выделение, ссылка или картинка; `⌥⇧S` — статья без окна, `⌥⇧M` — окно.

В начале страницы — карточка источника и ваша заметка. Можно выбрать папку и теги; по умолчанию вырезки попадают в папку «Из браузера».

**Скачать:** [последний выпуск](https://github.com/Slipcast-dev/MindNotes-WebClipper/releases/latest) — образ `MindNotes-Web-Clipper-<версия>.dmg`.

## Системы

macOS 15 Sequoia и новее, только Apple Silicon; Safari 18+, Chrome и браузеры на его основе. Нужна MindNotes 1.5.0
или новее, которая запускается на этом Mac: если она требует более новую macOS, установщик скажет об этом.

## Установка

Откройте **MindNotes Web Clipper.app** — дальше всё идёт само:

1. Установщик переносит себя в «Программы» (там его ищет Safari).
2. Добавляет плагин в MindNotes — MindNotes покажет разрешения, нажмите «Установить».
3. Находит браузеры на этом Mac и ставит расширение в каждый по очереди.
4. Подключение к MindNotes настраивается почти само: в течение 10 минут после установки расширение само просит ключ, а MindNotes один раз спрашивает «Подключить?» и показывает, кто просит.

Что браузеры не разрешают делать программам (правила Apple и Google):

- **Safari** — одна галочка: установщик открывает «Настройки» → «Расширения», включите MindNotes Web Clipper. Сборка подписана ad-hoc, поэтому сначала: «Настройки» → «Дополнения» → «Показывать функции для веб-разработчиков», затем «Разработка» → «Разрешить неподписанные расширения» (Safari сбрасывает это при перезапуске; постоянно — с подписью Developer ID).
- **Chrome, Arc, Brave, Edge, Vivaldi, Opera, Яндекс Браузер** — одно перетаскивание: установщик открывает страницу расширений, включите «Режим разработчика» и перетащите значок Web Clipper из окна установщика. После публикации в Chrome Web Store и этот шаг уйдёт: браузер сам предложит включить расширение.

Установщик показывает состояние каждого шага и отмечает готовые галочкой. Подключить браузер позже — «Настройки» MindNotes → «Расширения» → «Подключить браузеры».

## Известные ограничения

- Браузеры не дают программам ставить расширения сами: в Safari нужна одна галочка (а для сборки с подписью ad-hoc — ещё «Разрешить неподписанные расширения», Safari сбрасывает это при перезапуске); в Chrome и браузерах на его основе — «Режим разработчика» и одно перетаскивание, пока расширения нет в Chrome Web Store.
- Картинки с других сайтов скачивает MindNotes: картинки только по http, закрытые паролем на сайте или больше 8 МБ остаются ссылками.
- Извлечение статьи — своя упрощённая логика, на сложной вёрстке может захватить лишнее; тогда помогает режим «Выделение».

## Обновления

MindNotes сама проверяет обновления плагина при запуске и раз в сутки. Если новая версия не просит новых разрешений,
она ставится сама («Обновлять автоматически» в карточке плагина) — расширение в браузере перезапускается само.
Новые разрешения — по кнопке «Обновить» с вопросом. В карточке всегда есть «Проверить обновления».

Плагин не привязан к версии MindNotes: расширение смотрит, что умеет приложение (`features` в `/v1/status`), и
подстраивается. `minApp` ставится только при несовместимом изменении API.

## Разработка

Нужны macOS 15 или новее, Xcode (для расширения Safari; без него — `SKIP_SAFARI=1`) и Node.js 20+.

```bash
./scripts/test.sh                              # тесты расширения, установщика и договора об API
MINDNOTES_DIR=../MindNotes ./scripts/test.sh   # ещё и сверить договор с соседней копией MindNotes
./scripts/build.sh                             # build/MindNotes Web Clipper.app; SKIP_SAFARI=1 — без Xcode
```

Для проверки: `…/WebClipperInstaller --check` печатает, что найдено на Mac, ничего не меняя; `--no-auto` открывает окно без установки.

### Договор с MindNotes

Плагин не использует код MindNotes. Всё, на что он опирается, — адрес и порт локального API, пути, разрешения,
`features`, идентификаторы приложения и установщика — записано в [`contracts/plugin-api.json`](contracts/plugin-api.json).
Оригинал лежит в репозитории MindNotes, здесь копия; тесты обеих сторон сверяются с ним, а перед выпуском скрипт
сравнивает копию с оригиналом на GitHub. Меняется API — сначала договор в MindNotes, потом копия здесь.

### Выпуск

Версия плагина своя (`manifest.json`) и не зависит от версии MindNotes.

1. Поднять `version` в `manifest.json` **и** `browser/manifest.json`.
2. Перенести записи из «Не выпущено» в раздел версии в `CHANGELOG.md` и `CHANGELOG.ru.md`.
3. Проверить и выпустить:

```bash
DRY_RUN=1 ./scripts/release.sh   # проверить и собрать образ, ничего не публикуя
./scripts/release.sh             # тег webclipper-v<версия> и выпуск на GitHub
```

В выпуск кладутся образ, `plugin-manifest.json` и `SHA256SUMS.txt`. Выпуск публикуется только здесь: MindNotes 1.7.0 и
новее ищет плагин в этом репозитории. MindNotes до 1.7.0 искала его в репозитории приложения; она сначала обновится до
1.7.0, а потом получит и плагин. Если всё же нужна копия там: `MIRROR_TO_APP_REPO=1` (выпуск будет «не последним»,
иначе MindNotes не нашла бы свои обновления); убрать копии — `./scripts/remove-app-copies.sh`.

## Как устроено

```text
Installer/              программа-установщик (SwiftUI): браузеры, MindNotes, Safari, подсказка для Chromium
browser/manifest.json   Manifest V3, общий для Chrome и Safari
browser/extract.js      извлечение статьи и HTML → Markdown прямо на странице (без внешних библиотек)
browser/background.js   меню, клавиши, скриншот, картинки, отправка, самоподключение
browser/api.js          клиент локального API: 127.0.0.1:27183, ключ в chrome.storage.local
browser/popup.*         окно: режим, название, папка, теги, заметка
browser/_locales/       тексты расширения: русский и английский
manifest.json           описание плагина для MindNotes: разрешения, компоненты, откуда обновления
contracts/              копия договора об API с MindNotes
scripts/                сборка, тесты, выпуск
tests/                  тесты (node --test)
```

Расширение для Chromium лежит в `~/Library/Application Support/MindNotes Web Clipper/chrome`, расширение Safari — внутри установщика. Постоянный доступ у расширения — только к `127.0.0.1`. Картинки самой страницы скачивает браузер, а картинки с других сайтов (CDN) — MindNotes по адресу: так расширению не нужен доступ ко всем сайтам.

Безопасность: код плагина не исполняется внутри MindNotes; MindNotes принимает запросы только от страниц расширений
и только с ключом, выданным после вашего согласия, и только в пределах разрешений из `manifest.json`. Подробно — ADR-0019
в репозитории MindNotes и [SECURITY.md](SECURITY.md).
